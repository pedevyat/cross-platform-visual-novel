# cross-platform-visual-novel

Мобильное приложение с использованием React Native или аналогичного фреймворка. 

- [ ] Приложение должно работать в браузере и на мобильных устройствах (iOS и/или Android).

Содержание: небольшая визуальная новелла.

Функциональные требования:

- [ ] Возможность выбора различных вариантов действий, которые влияют на развитие сюжета.
- [ ] Небольшое игровое состояние (3-5 переменных).
- [ ] Бессерверная архитектура: данные лежат на статическом хостинге, код на бэкенде не выполняется.
- [ ] Игра должна понимать, что файлы на статическом хостинге могут быть обновлены, и корректно обрабатывать эти изменения.
- [ ] Текст и арт для этого задания можно сгенерировать, если нет возможности сделать самостоятельно. На оценку художественная ценность не влияет.
