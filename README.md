# cross-platform-visual-novel

Кросс-платформенное приложение, который представляет собой новеллу с использованием `React Native`. Приложение работает в браузере и на мобильных устройствах. Сайт развернут на [GitHub Pages](https://pedevyat.github.io/cross-platform-visual-novel/)

## СТЕК
- UI: `React Native`
- Сборка: `Expo`
- Сюжетные линии: `inkjs`

## ПЕРСОНАЖИ
- два игрока: Леха и персонаж, за которого ведем с ним диалог, пусть его зовут так же как и Вас,

Функциональные требования:
- [x] Возможность выбора различных вариантов действий, которые влияют на развитие сюжета.
- [x] Небольшое игровое состояние (3-5 переменных).
- `respect` — уважение Лёхи,
- `trust` — доверие,
- `patience` — терпение (при 0 Лёха уходит),
- `has_notes` — есть ли у героя конспекты.
- От них зависят доступные варианты и концовка.
  
- [x] Бессерверная архитектура: данные лежат на статическом хостинге, код на бэкенде не выполняется.
- Сайт собирается в статические файлы (web.output: `"single"`) и раздаётся с `GitHub Pages.` Сюжет проигрывается в браузере или на телефоне через `inkjs`, своих серверных эндпоинтов и базы данных нет.
- [x] Игра должна понимать, что файлы на статическом хостинге могут быть обновлены, и корректно обрабатывать эти изменения.
- Сюжет лежит на хостинге отдельным файлом story.json и загружается при старте в обход кеша. Версия сюжета — хеш его содержимого. Сохранения хранятся вместе с версией: если она не совпадает с текущей, старое сохранение сбрасывается. Раз в 5 минут и при возврате в приложение игра проверяет хостинг и предлагает перейти на новую версию. Если хостинг недоступен, используется копия сюжета, вшитая в приложение.
- [x] Текст и арт для этого задания можно сгенерировать, если нет возможности сделать самостоятельно. На оценку художественная ценность не влияет.
